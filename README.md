# Gathri — A campus-only marketplace

Gathri is a college-only marketplace prototype where students buy and sell what campus life actually cycles through: assignments and files, drawing sheets, drafting tools, lab gear, electronics, books, and hostel essentials.


![Gathri home](screenshot.png)

## What it does

- 17 seeded listings in rupees, in fixed sorted categories, with Special Offers and Most Popular sections.
- Search with a Not Found state, sort, and filters.
- Condition indicators, seller profiles, and reviews, so trust is part of the layout.
- A cart and a 5-step prototype checkout built around meeting on campus and checking the item in person before paying.
- A working sell form, so students can list their own items, and a full profile section.

## Status

Working prototype, built November 2026. No real payment is taken. Built to test whether a campus-only marketplace beats the group chat chaos it replaces.
